# chameleon_n1_planar_solutions
Package to construct analytic solutions for the planar (n=1) chameleon equation of motion, for a system of N discrete regions of uniform density. Uses the equations derived in "[https://arxiv.org/abs/2611.30712](https://arxiv.org/abs/2611.30712)".


# project_code_and_data.zip
Containing the code and data used throughout the project that culminated in the paper "[https://arxiv.org/abs/2611.30712](https://arxiv.org/abs/2611.30712)". This includes code used to develop the above package and the code/data used to generate the plots used in the paper.
